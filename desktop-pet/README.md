# ZZZ Idol Desktop Pet

爱芮、南宫、千夏的 macOS / Windows 桌宠应用。

当前功能：

- Tauri 2 + Vite + TypeScript 工程骨架。
- 爱芮、南宫、千夏同时运行在三个独立的透明、无边框、默认置顶窗口中。
- 按需创建的普通设置窗口；关闭后销毁 WebView 并释放页面资源。
- 单实例保护：重复启动会复用当前进程并打开设置窗口，不会再生成一组三角色窗口。
- Rust 与前端错误写入受大小和数量限制的本地日志；设置页可导出包含版本、窗口、设置摘要、联动快照和最近日志的诊断报告。
- 系统托盘与人物右键菜单：显示全部、分别显示/隐藏角色、打开设置、隐藏全部、退出。
- 仅向三个桌宠窗口开放原生拖拽、窗口位置和缩放因子所需的最小 capability。
- 开发与生产前端资源路径。
- Three.js 0.155.0 + Spine Runtime 4.2.42。
- 爱芮、南宫、千夏的动作、皮肤、表情叠加、物理约束和固定实例加载。
- 设置页支持分别显示和缩放三个角色，以及全局置顶、漫步频率/速度、互动反馈、视线追踪、性能/帧率和开机启动。
- 统一版本化 JSON 配置采用跨平台原子替换，支持旧缩放/位置迁移、损坏文件备份恢复，并与托盘快捷开关同步。
- 三个独立窗口通过 Rust `CoordinationManager` 共享运行快照、场景令牌、冷却和取消状态；不新增 WebView，也不改变逐像素命中链路。
- 联动 MVP 支持互相注视、单击/双击节制回应、集合/散开和集合到当前角色；自动小剧场、跟随和主动让位仍关闭。
- 设置 Schema 6 保留联动与手动托举设置，新增独立且默认关闭的“漫步时自动托举”开关；旧配置升级不会自动启用。
- 单击、双击、连续点击、悬停、动作—表情绑定与播放令牌状态恢复。
- 以角色可见头顶中央为固定悬点的整体摆动，包含拖拽速度响应与释放后惯性回正。
- 5～11 秒随机停留，在左、右、左上、左下、右上、右下六个方向自由漫步；复用集合移动的二维亚像素步进和现有走路动画，按水平分量镜像朝向。斜向与横向总速度一致，沿途受工作区限制；边缘空间不足时转向，狭窄工作区退回可用方向或停留。漫步频率、速度设置以及点击/拖拽中断继续生效。
- 三角色共享眼部控制骨的鼠标视线追踪；透明区域也可通过全局光标采样持续跟随，并在反馈动作和拖拽时平滑回正。
- 原生显示器工作区边界夹取、稳定位置保存、启动恢复与断屏回退。
- 动作完成回调、资源销毁、自适应缩放和 WebGL context 恢复。
- 三角色运行资源 SHA-256 校验脚本。
- 从三组训练变体中独立提取“向上托举”动作包：身体轨道统一命名为 `动作_托举`，叠加 `表情_使劲`，并保留各自完整骨骼、物理约束与透明纹理。动作包登记在 `public/characters/special-actions.json`，不直接合并进不兼容的主角色骨骼。
- 开启“手动窗口托举”后，把角色的可见头顶拖到普通窗口底边附近（72 CSS px 内）并松手，即可持续吸附并切换托举骨骼，不受自动托举的 10 秒限制。首次检测使用可见头顶，托举后使用各角色真实手掌网格的上沿对齐，随角色大小自动计算，并在每帧补偿手掌动画位移。目标窗口移动时角色按各自水平锚点跟随，三名角色可以同时绑定同一个窗口，桌宠不会主动移动或调整第三方窗口。
- 开启“漫步时自动托举”和“自动漫步”后，角色走到普通窗口底边附近（可见头顶距底边不超过 72 CSS px、水平位置在窗口范围内）时，会自动托举 10 秒。头顶略高于底边、身体已经在下方时也能触发，不要求头顶完全低于底边。计时从动作加载并贴边完成后开始；结束后恢复主角色、原来的漫步高度与朝向，按原漫步节奏继续活动。每名角色独立计时，放下后冷却 15 秒再允许自动吸附。自动查询每 400ms 最多一次，未命中不弹提示、不刷日志；拖拽、悬停、调试面板、集合联动和其他非自由漫步状态不触发。用户拖拽接管会取消自动计时；开启手动托举后再次拖拽吸附即持续托举。关闭自动开关只解除自动绑定，不影响手动绑定。
- 托举空间检查只使用两轮动画采样得到的可见范围，不将 520×600 透明画布当作人物体积；仅托举专用原生移动允许透明留白越过工作区，普通漫步仍保持原边界。可见人物仍须完整留在工作区。全屏/最大化、最小化、不适用的系统窗口和可见空间不足的目标会被排除；拖离底边或按 `Esc` 可放下。未找到附近窗口、空间不足、目标失效等原因会短暂显示并记录日志。

透明安全边界固定为 520×600，角色仍按 360×480 视觉基准缩放。Rust 以 25Hz 轮询全局光标、窗口原点和缩放因子，Three.js/WebGL 用 3×3 Alpha 探针命中当前角色像素，再调用原生窗口 API 让透明像素穿透；拖拽和调试控件期间强制保持可交互。该链路已在 macOS 生产包验证，Windows 行为仍需后续实机验证。

Windows 和 macOS 手动拖拽均跟随全局光标，允许角色窗口的透明留白越过屏幕顶部。macOS 仅对三个标记过的桌宠窗口放开 AppKit 的顶部边界校正，设置窗口继续使用原有约束。拖拽使用 AppKit 逻辑坐标，在主线程完成最后一次移动后才结束并保存位置；按 Esc 可回到本次拖拽起点。横向自由漫步会保留可操作的顶部拖拽高度，向下斜走时逐步回到工作区，不会在第一帧突然跳下，也不会主动向上扩大越界范围。macOS 重启也会恢复这些位置；不可操作或原显示器已移除的位置仍会回退到工作区。

普通模式不显示桌宠浮动状态提示（包括加载、托举结果与失败提示），日志仍保留。先在设置中开启“调试模式”可显示这些提示，关闭后立即隐藏；聚焦任一宠物窗口后按 `D` 可以打开该角色的自检面板。按 macOS `⌘,` 或 Windows `Ctrl+,` 可以打开设置。自检面板支持切换动作、皮肤与表情，运行资源/表情/交互状态自检，选择六个方向模拟漫步、重复加载以及模拟 WebGL 恢复。调试 API 同样支持 `window.__zzzPetDebug.simulateWalk(120, "left-up")`，漫步快照提供方向、当前 X/Y 和目标 X/Y。

## 番茄钟

设置页的“显示番茄钟”开关、系统托盘或人物右键菜单中的“番茄钟”可打开桌面置顶窗口。设置页仅提供显示开关；全部计时操作都在独立窗口中完成。窗口直接使用原始 ANGELS 背景，粉色数字、按钮与进度条，拖动顶部标志可以移动窗口。窗口底部提供“关闭”按钮，也可通过设置页的显示开关关闭；关闭窗口不停止计时。

- 默认 2 个番茄钟，每轮专注 25 分钟、中间休息 5 分钟；开始前可修改轮数（1～99）、专注（1～180 分钟）和休息（1～60 分钟）。最后一轮不追加休息。
- 支持暂停/继续、运行或暂停时“+1 个”、跳过休息和确认结束本组。暂停休息时跳过会进入暂停的下一轮专注。
- “声音设置”仅提供声音开关与音量，不提供试听；整个应用仅有一个原生音频播放服务。MP3 嵌入程序，不依赖开发目录或隐藏 WebView。暂停时将开始铃声的两个音节交换顺序播放，每个音节保持正向播放。
- 关闭计时窗、关闭设置、隐藏桌宠均不停止计时。计时窗重新打开会读取后台进度，并恢复仍可见的窗口位置。
- 计时使用单调时间，进度与偏好独立保存在应用配置目录的 `pomodoro-session.json`，不变更现有桌宠设置 Schema。状态操作即时保存，运行时每 10 秒保存检查点；重启后恢复为暂停，崩溃可能损失最后约 10 秒进度。
- 检测到超过 5 秒的调度/墙钟空档或时钟回拨时，保守暂停，避免把休眠或中断时间累计为专注。此机制也可能在系统严重卡顿或手动改时后暂停，需要点击继续。
- 铃声失败或进度保存失败在窗口内提示，不停止计时。后台不申请系统通知权限。

## 开发

```bash
npm install
npm run tauri dev
```

## 验证

```bash
npm run build
npm run validate:phase2
npm run validate:phase3
npm run validate:phase4
npm run validate:phase5
npm run validate:phase6
npm run validate:phase7
npm run validate:coordination
npm run validate:diagnostics
npm run validate:lift-action
npm run validate:window-lift
npm run validate:windows-prep
npm run tauri build -- --no-bundle
npm run tauri build -- --bundles app
cargo check --manifest-path src-tauri/Cargo.toml
```

托举渲染核验：运行 `npm run dev`，打开 `http://localhost:1420/tests/fixtures/window-lift.html`，可同时检查三个真实托举骨骼在 60% / 100% 大小时的手掌贴边效果。该页面不进入发布构建，也不替代原生窗口拖动、跨屏和权限验收。

Windows x64 的 GitHub Actions 构建会生成 NSIS `.exe` 与 MSI `.msi`，并将构建身份和 SHA-256 一起上传为 Artifact。CI Runner 只验证 Windows 工具链构建，透明窗口、DPI、拖拽和逐像素穿透仍需在 Windows 11 实机上验证。

macOS 应用包输出到：

```text
src-tauri/target/release/bundle/macos/ZZZ Idol Desktop Pet.app
```
